# Nmap পরিচিতি ও গাইড

---

## 01. Nmap কী? (What is Nmap?)

Nmap (Network Mapper) হলো একটি ফ্রি ও ওপেন সোর্স নেটওয়ার্ক স্ক্যানিং টুল যা বিভিন্ন ডিভাইস ও সার্ভারের তথ্য সংগ্রহে ব্যবহৃত হয়।

Nmap দিয়ে তুমি জানতে পারবে:
- কোন কোন ডিভাইসে নেটওয়ার্কে কানেক্টেড আছে
- ডিভাইসের কোন পোর্ট খোলা আছে
- সার্ভিস ও অপারেটিং সিস্টেম কি চলছে
- নিরাপত্তার ঝুঁকি বা ভলনারেবিলিটি আছে কিনা

এটি হ্যাকিং নয়, বরং সাইবার নিরাপত্তার জন্য ব্যবহৃত একটি প্রয়োজনীয় টুল।

## 02. Nmap ইনস্টলেশন (Installation Guide)

### Windows-এ ইনস্টলেশন:

1. অফিসিয়াল ওয়েবসাইট থেকে ডাউনলোড করো:  
   https://nmap.org/download.html

2. Windows Installer (.exe) ফাইল ডাউনলোড করে রান করো।

4. ইন্সটল হয়ে গেলে, Command Prompt (CMD) খুলে টাইপ করো:

# 03. Nmap এর বেসিক ধারণা (Basic Concepts)

---

## IP Address এবং Port কী?

- **IP Address**: নেটওয়ার্কে প্রতিটি ডিভাইসের ইউনিক ঠিকানা।  
  যেমন: 192.168.1.1, 10.0.0.5 ইত্যাদি।  

- **Port**: প্রতিটি ডিভাইসে অনেক সার্ভিস চলে। প্রতিটি সার্ভিস নির্দিষ্ট পোর্ট নাম্বার ব্যবহার করে।  
  যেমন: ওয়েব সার্ভিস সাধারণত পোর্ট ৮০ বা ৪৪৩ এ চলে। SSH সার্ভিস চলে পোর্ট ২২ এ।  

---

## Nmap দিয়ে কী ধরণের কাজ করা যায়?

| কাজ                      | ব্যাখ্যা                                   |
|--------------------------|-------------------------------------------|
| **Host Discovery (Ping Sweep)** | নেটওয়ার্কে কোন ডিভাইস অনলাইনে আছে তা খুঁজে বের করা। |
| **Port Scanning**            | একটি ডিভাইসে কোন কোন পোর্ট খোলা (open) আছে তা নির্ধারণ করা। |
| **Service Version Detection**| খোলা পোর্টে কোন সার্ভিস চলছে এবং তার ভার্সন কী তা নির্ণয়। |
| **Operating System Detection**| ডিভাইসের অপারেটিং সিস্টেম (যেমন Windows, Linux) চেনা। |
| **Vulnerability Scanning**  | নিরাপত্তার দুর্বলতা ও ঝুঁকি শনাক্ত করা (NSE স্ক্রিপ্ট দিয়ে)। |

---

## Nmap এর কাজের ধরণ

### ১. Host Discovery (Ping Sweep)
নেটওয়ার্কে কোন কোন IP ঠিকানায় ডিভাইস বা কম্পিউটার অনলাইনে আছে তা খুঁজে বের করার প্রক্রিয়া।  
উদাহরণ:  
```bash
nmap -sn 192.168.1.0/24
``` 
 
### ২. Port Scanning
একটি কম্পিউটার বা সার্ভারে কোন কোন পোর্ট খোলা আছে তা নির্ণয় করা।
উদাহরণ:

```bash    
nmap -p 1-1000 192.168.1.1
```
### ৩. Service & Version Detection
কোন পোর্টে কোন সার্ভিস চলছে এবং তার ভার্সন কী তা নির্ধারণ।
উদাহরণ:

```bash 
nmap -sV 192.168.1.1
```
### ৪. Operating System Detection
টার্গেট ডিভাইসের অপারেটিং সিস্টেম ও তার ভার্সন শনাক্ত করা।
উদাহরণ:

``` bash 
nmap -O 192.168.1.1
```
### ৫. Vulnerability Scanning
নিরাপত্তার দুর্বলতা শনাক্ত করতে বিশেষ NSE স্ক্রিপ্ট চালানো।
উদাহরণ:

```bash 
nmap --script vuln 192.168.1.1
Port এবং Service এর সংক্ষিপ্ত পরিচিতি
Port Number	সার্ভিস	বর্ণনা
80	HTTP	ওয়েব সার্ভার
443	HTTPS	সিকিউর ওয়েব সার্ভার
22	SSH	রিমোট লগইন সার্ভিস
21	FTP	ফাইল ট্রান্সফার সার্ভিস
3306	MySQL	ডাটাবেস সার্ভিস
```
### সংক্ষিপ্ত টিপস
- Nmap পোর্ট “open” দেখালে অর্থ ওই পোর্টে সার্ভিস চলছে এবং রিকোয়েস্ট গ্রহণে প্রস্তুত।
- “Closed” মানে পোর্ট বন্ধ, “Filtered” মানে ফায়ারওয়াল বা নিরাপত্তার কারণে পোর্ট ব্লক হয়েছে।
- অন্যের অনুমতি ছাড়া নেটওয়ার্ক স্ক্যানিং করা বেআইনি হতে পারে, সতর্ক থাকো।

### উপসংহার
Nmap হলো নেটওয়ার্ক ও সিকিউরিটি বিশ্লেষণের একটি শক্তিশালী টুল যা তোমার কম্পিউটার ও সার্ভারের পোর্ট, সার্ভিস, OS, এবং নিরাপত্তার তথ্য জানতে সাহায্য করে।
তাই এটি শেখা তোমার জন্য খুবই উপকারী হবে, বিশেষ করে যদি তুমি সাইবার সিকিউরিটি বা নেটওয়ার্ক ম্যানেজমেন্টে আগ্রহী হও।
