# 02-basic_scanning

এই ফোল্ডারটি Nmap এর বেসিক স্ক্যানিং সম্পর্কিত বিষয়গুলো নিয়ে কাজ করে। এখানে নেটওয়ার্ক স্ক্যানিংয়ের বিভিন্ন পদ্ধতি ও কমান্ড ব্যাখ্যা করা হয়েছে।

---

## ১. ping_sweep.md

**পিং সুইপ** হল নেটওয়ার্কের নির্দিষ্ট রেঞ্জে থাকা ডিভাইসগুলোর অনলাইন/লাইভ স্ট্যাটাস চেক করার পদ্ধতি।  
এখানে প্রতিটি IP ঠিকানায় পিং (ping) পাঠিয়ে দেখা হয় কোন কোন ডিভাইসে সাড়া আসে।  
উদাহরণ:  
```bash
nmap -sn 192.168.1.0/24
```
এই কমান্ড 192.168.1.0 থেকে 192.168.1.255 পর্যন্ত সব IP তে পিং পাঠাবে এবং অনলাইন ডিভাইসগুলো তালিকাভুক্ত করবে।
 
```
nmap -sn 192.168.1.149-198
```
তুমি যে nmap -sn 192.168.1.149-198 কমান্ড দিয়েছিলে, তার ফলাফল ভালোভাবেই দেখাচ্ছে তোমার নেটওয়ার্কে ওই রেঞ্জের মধ্যে ৫টি ডিভাইস অনলাইনে আছে।

## ২. port_scanning.md
পোর্ট স্ক্যানিং হলো নির্দিষ্ট একটি ডিভাইসে কোন কোন পোর্ট খোলা আছে তা খুঁজে বের করার প্রক্রিয়া।
পোর্ট খোলা থাকলে সেটি দিয়ে সার্ভিস চালু থাকে (যেমন HTTP, SSH)।
উদাহরণ:

```bash 
nmap -p 1-1000 192.168.1.10
```
এই কমান্ড IP 192.168.1.10 এর ১ থেকে ১০০০ নম্বর পোর্ট পর্যন্ত স্ক্যান করে খোলা পোর্টগুলো দেখাবে।

## ৩. scanning_single_ip.md
একক IP স্ক্যানিং হলো নির্দিষ্ট একটি IP ঠিকানায় নেটওয়ার্ক বা পোর্ট স্ক্যানিং করা।
এতে তুমি নির্দিষ্ট ডিভাইসের সার্ভিস, অপারেটিং সিস্টেম, ভলনারেবিলিটি ইত্যাদি পরীক্ষা করতে পারো।
উদাহরণ:

```bash 
nmap -A 192.168.1.15
```
এই কমান্ড IP 192.168.1.15 এর ওপর অ্যাডভান্সড স্ক্যানিং করবে (সার্ভিস ডিটেকশন, OS ডিটেকশন, স্ক্রিপ্ট ইত্যাদি)।

## ৪. scanning_ip_range.md
IP রেঞ্জ স্ক্যানিং হলো নির্দিষ্ট একটি পরিসরের মধ্যে একাধিক IP ঠিকানায় স্ক্যান করা।
এটি ব্যবহার করে পুরো নেটওয়ার্ক বা সাবনেট স্ক্যান করা যায়।
উদাহরণ:

```bash 
nmap -p 80 192.168.1.1-50
```
এই কমান্ড 192.168.1.1 থেকে 192.168.1.50 পর্যন্ত প্রতিটি IP এর পোর্ট ৮০ স্ক্যান করবে।
 

- এই ফোল্ডার থেকে তুমি শিখতে পারবে—
- নেটওয়ার্কে ডিভাইস খুঁজে পাওয়ার সহজ পদ্ধতি
- কিভাবে পোর্ট স্ক্যান করে সার্ভিস খুঁজে পাওয়া যায়
- নির্দিষ্ট IP বা IP রেঞ্জে স্ক্যানিং করা
