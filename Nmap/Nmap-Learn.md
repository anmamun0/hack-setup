# 🔍 Nmap কী?

**Nmap** (Network Mapper) হলো একটি **ফ্রি ও ওপেন সোর্স টুল** যা কম্পিউটার নেটওয়ার্কে থাকা ডিভাইস ও সার্ভার সম্পর্কে তথ্য সংগ্রহ করার জন্য ব্যবহার হয়।

➡️ এটি মূলত **নেটওয়ার্ক স্ক্যানিং**, **পোর্ট স্ক্যানিং**, এবং **ভুলে যাওয়া ডিভাইস খুঁজে বের করা**, **সার্ভার সিকিউরিটি চেক** ইত্যাদির জন্য ব্যবহৃত হয়।

---

## ✅ Nmap দিয়ে কী কী করতে পারবে?

| কাজ                                              | বিস্তারিত                                                                 |
| ------------------------------------------------ | ------------------------------------------------------------------------- |
| 🔌 ১. **Port Scanning**                          | একটি কম্পিউটারে কোন কোন **port খোলা** আছে, তা বের করতে পারবে (যেমন 80, 443, 22) |
| 🌐 ২. **IP/Device খুঁজে বের করা**                | নেটওয়ার্কে কে কে কানেক্টেড আছে, কোন কোন IP alive আছে                     |
| 🛠️ ৩. **Service & Version Detection**           | কোন port-এ কোন service চলছে (যেমন HTTP server, SSH), এবং তার version    |
| 💻 ৪. **Operating System চেনা**                  | টার্গেট সিস্টেমের OS (Windows, Linux ইত্যাদি) detect করতে পারে          |
| 🔒 ৫. **Vulnerability খোঁজা (নিরাপত্তার ছিদ্র)** | NSE Script ব্যবহার করে কিছু security vulnerability detect করা যায়       |
| 🧠 ৬. **Network Inventory**                      | কে কোথায় কী চালাচ্ছে তার **পুরো মানচিত্র** বানানো যায়                   |
| ⚙️ ৭. **Firewall/IDS detect করা**                | ফায়ারওয়াল বা intrusion detection system detect করা যায়                  |

## 🛰️ Ping Sweep কী?

**Ping Sweep** এর মানে হলো—

একটি নির্দিষ্ট নেটওয়ার্ক রেঞ্জের (যেমন `192.168.1.0` থেকে `192.168.1.255` পর্যন্ত) সব আইপি ঠিকানায় একের পর এক “ping” পাঠিয়ে দেখা হয় ওই আইপিগুলোতে কোন ডিভাইস অনলাইনে আছে কি না।

### ✅ সহজ বাংলায়:
ধরো, তোমার বাসায় ২৫৬টি ঘর (IP) আছে।  
তুমি প্রতিটি ঘরে দরজা খুলে দেখে আসছো কেউ আছে কি না।

- যেই ঘর থেকে ‘**আছে**’ এর সিগনাল পাবে, সেটা বুঝবে **ওই ঘরে কেউ আছে** বা **ডিভাইস চালু আছে**।
- যে ঘর থেকে **সিগনাল পাওয়া যাবে না**, বুঝবে **ওই ঘরে কেউ নেই**।

---

### ❓ কেন লাগে?

নেটওয়ার্কে কোন কোন ডিভাইস **সক্রিয় বা অনলাইন** আছে সেটা জানার জন্য।

যেমন: কোন ফোন, কম্পিউটার, প্রিন্টার ইত্যাদি কানেক্টেড আছে কি না — সেটা জানার জন্য।

---

### ⚙️ কিভাবে হয়?

- `ping` হলো একটি ছোট নেটওয়ার্ক কমান্ড যা ডিভাইসের উপস্থিতি যাচাই করে।
- **Ping Sweep** মানে অনেকগুলো IP তে ধারাবাহিকভাবে ping পাঠানো।

# 🔸 ১. পোর্ট স্ক্যান:

```bash
nmap -p 1-1000 192.168.0.1
```

##### ১ থেকে ১০০০ নাম্বার পোর্টে কী খোলা তা বের করবে।

---

### 📌 Port Scanning মানে হলো —

##### 👉 কোনো কম্পিউটার বা সার্ভারে কোন কোন “পোর্ট” খোলা (open) আছে, তা খুঁজে বের করা।

এটা এমন যেন তুমি একটা দরজার সামনে দাঁড়িয়ে ধীরে ধীরে প্রতিটি দরজায় টোকা মারছো —  
**“এই দরজাটা খোলা আছে?”**  
কম্পিউটারে এই দরজাগুলোই হলো **Port**।

---

### 🔹 Port কী?

কম্পিউটার যখন ইন্টারনেটে বা লোকাল নেটওয়ার্কে কোনো সার্ভিস চালায় (যেমনঃ Web server, FTP, SSH), তখন তা এক বা একাধিক port number-এ চলে।

**উদাহরণ:**

- Port 80 → HTTP (Web Server)  
- Port 443 → HTTPS (Secure Web)  
- Port 22 → SSH (Remote Login)  
- Port 21 → FTP  

---

### 📘 উদাহরণ দিয়ে বুঝি:

ধরো তুমি command দাও:

```bash
nmap -p 1-1000 192.168.0.1
```

**এটা কি করে?**

👉 এটা ১ থেকে ১০০০ পর্যন্ত সব পোর্টে “টোকা” দেয় এবং দেখে:

- কোনগুলো **open**  
- কোনগুলো **closed**  
- কোনগুলো **filtered** (firewall-এ আটকে গেছে)

---

### ✅ Output দেখাবে এরকম:

```bash
PORT     STATE  SERVICE
22/tcp   open   ssh
80/tcp   open   http
443/tcp  closed https
3306/tcp open   mysql
```

এখানে বোঝা যাচ্ছে:

- `22 (SSH)`, `80 (HTTP)`, `3306 (MySQL)` → **ওপেন**  
- `443` → **ক্লোজড**

---

### 🤔 কেন এটা গুরুত্বপূর্ণ?

- যদি অপ্রয়োজনীয় পোর্ট খোলা থাকে, হ্যাকাররা সেটা দিয়ে system-এ ঢুকতে পারে  
- একটি সার্ভার বা ডিভাইসে কোন সার্ভিস চলছে — তা detect করা যায়  
- Vulnerability assessment করার জন্য পোর্ট জানা দরকার

---

### ⚠️ সতর্কতা:

🔴 Port scanning একটা প্রোফেশনাল টুল, কিন্তু **অন্যের permission ছাড়া ব্যবহার করলে এটা “illegal”** হতে পারে।

✅ নিজের **রাউটার**, **লোকাল সার্ভার**, অথবা **virtual lab**-এ scan করতে পারো practice করার জন্য।








# 📘 Nmap এবং Port Scanner নিয়ে পূর্ণ গাইড (বাংলা)

## 🔹 Port মানে কি আমার Laptop এর Hotspot-এ কয়টা Connected সেটাই?

**না।**

Hotspot এ কয়টা ডিভাইস সংযুক্ত আছে, সেটা Device Count বা IP Connection। আর Port মানে হলো — তোমার কম্পিউটার বা ফোনের ভিতরের দরজাগুলোর মতো, যেগুলো দিয়ে আলাদা আলাদা সার্ভিস চলে।

---

## 🔍 তাহলে, “Port” মানে কী?

Port হলো —
তোমার ল্যাপটপ বা কম্পিউটার যখন ইন্টারনেট/নেটওয়ার্কে কোন সার্ভিস চালায় (যেমনঃ ওয়েব, ফাইল ট্রান্সফার, রিমোট লগইন), তখন তা একটা নির্দিষ্ট নম্বরযুক্ত গেট/door (port) দিয়ে চলে।

🧠 উদাহরণ:

| Port | সার্ভিস | কাজ         |
| ---- | ------- | ----------- |
| 80   | HTTP    | ওয়েবসাইট    |
| 443  | HTTPS   | সিকিউর ওয়েব |
| 22   | SSH     | রিমোট লগইন  |
| 3306 | MySQL   | ডাটাবেস     |

---

## 🔌 Port vs Device Connection

| বিষয়             | Port                          | Device Connection       |
| ---------------- | ----------------------------- | ----------------------- |
| মানে কী          | কম্পিউটারের ভিতরের দরজা       | Wi-Fi-তে কয়জন সংযুক্ত   |
| উদাহরণ           | Port 80 = HTTP, Port 22 = SSH | IP: 192.168.1.5         |
| ব্যবহার কোথায় হয় | সার্ভিস চলতে কোন গেট লাগবে    | Wi-Fi client কাউ খুঁজবে |
| ব্যবহার করে কে?  | Nmap, Server, Hacker          | Router, Hotspot         |

---

## ❓ কেন 80/443 পোর্ট ওপেন দেখায়, যদিও আমি ব্রাউজার চালাইনি?

কারণ:

- Port open মানে সার্ভিস চালু — সেটা ব্যাকগ্রাউন্ডেও হতে পারে।
- যেমন: রাউটারের Admin Panel সবসময় Port 80/443 এ চলছে।

### সারাংশ:

| বিষয়                  | সত্যিই কী ঘটে?                      |
| --------------------- | ----------------------------------- |
| ব্রাউজার চালানো হয় না | কিন্তু ওয়েব সার্ভার ২৪/৭ চলে        |
| Nmap স্ক্যান          | পোর্টে সার্ভিস আছে কিনা পরীক্ষা করে |
| পোর্ট open মানে       | সার্ভিস রিকোয়েস্ট নিতে প্রস্তুত     |

### 🎯 উদাহরণ:

```bash

nmap -p 8000 127.0.0.1
```

| অংশ           | অর্থ                                   |
| ------------- | -------------------------------------- |
| `nmap`        | স্ক্যান করার টুল                       |
| `-p`          | পোর্ট সংখ্যা বা রেঞ্জ উল্লেখ করার অপশন |

| `192.168.1.1` | স্ক্যান করার টার্গেট IP ঠিকানা         |
| `127.0.0.1`   | নিজের কম্পিউটার (localhost)            |

## 🔍 গুরুত্বপূর্ণ Nmap কমান্ডগুলো

| কাজ                              | কমান্ড উদাহরণ             |
| -------------------------------- | ------------------------- |
| কে অনলাইনে আছে দেখো (ping sweep) | `nmap -sn 192.168.1.0/24` |
| কোন কোন পোর্ট খোলা আছে           | `nmap -p 1-1000 <IP>`     |
| OS খুঁজে বের করো                 | `nmap -O <IP>`            |
| সার্ভিস ভার্সন চেক করো           | `nmap -sV <IP>`           |
| Vulnerability চেক                | `nmap --script vuln <IP>` |
| Traceroute                       | `nmap --traceroute <IP>`  |
| অ্যাডভান্স স্ক্যান (Aggressive)  | `nmap -A <IP>`            |

> nmap -sn 192.168.1.0/24
এই কমান্ড পুরো নেটওয়ার্কে (192.168.1.0 থেকে 192.168.1.255 পর্যন্ত) ping sweep করে কোন IP এ ডিভাইস অনলাইনে আছে জানাবে, কিন্তু পোর্ট স্ক্যান করবে না।

> nmap -sn 192.168.1.149-198
তুমি যে nmap -sn 192.168.1.149-198 কমান্ড দিয়েছিলে, তার ফলাফল ভালোভাবেই দেখাচ্ছে তোমার নেটওয়ার্কে ওই রেঞ্জের মধ্যে ৫টি ডিভাইস অনলাইনে আছে।

#### ২. OS Version ও অন্যান্য তথ্য জানার জন্য
##### (ক) Nmap ব্যবহার:
- OS ডিটেকশনের জন্য Nmap এ -O অপশন ব্যবহার করো (root/administrator প্রিভিলেজ দরকার হতে পারে):

```bash
nmap -O <target-ip>
```

উদাহরণ:

```bash
nmap -O 192.168.1.189
```

এতে ওই IP তে থাকা ডিভাইসের অপারেটিং সিস্টেমের তথ্য (যেমন Windows, Linux, Android) এবং ভার্সনের একটি আন্দাজ পাওয়া যায়।

#### (খ) Nmap দিয়ে সার্ভিস ভার্সন ডিটেকশন:
সার্ভিস বা অ্যাপ্লিকেশনের ভার্সন দেখতে:

```bash
nmap -sV <target-ip>
```

৩. অ্যাপস বা সফটওয়্যার ব্যবহার
- **Fing (মোবাইল অ্যাপ)**: নেটওয়ার্কে যুক্ত ডিভাইসের ব্র্যান্ড, নাম, OS এর মতো তথ্য দেখায়।
- **Advanced IP Scanner (Windows)**: একইভাবে তথ্য দেয়।
- **Wireshark**: ডিভাইসের নেটওয়ার্ক ট্রাফিক বিশ্লেষণ করে আরো ডিটেইলস পেতে পারে।

### 🔸 ২. নির্দিষ্ট সার্ভিস ও ভার্সন দেখো:
```bash
nmap -sV 192.168.0.1
```
➡️ কোন সার্ভিস চলছে ও তার version নামিয়ে আনবে।

--- 

### 🔸 ৩. লাইভ ডিভাইস খোঁজো (ping scan):
```bash
nmap -sn 192.168.0.0/24
```
➡️ পুরো Wi-Fi নেটওয়ার্কে কে কে কানেক্টেড আছে, তার IP দেখাবে।

---
### 🔸 ৪. OS চেনার চেষ্টা:

```bash
nmap -O 192.168.0.1
```
➡️ Target সিস্টেম Windows না Linux তা বের করবে।

---

### 🔸 ৫. Vulnerability স্ক্যান (NSE script):
```bash
nmap --script vuln 192.168.0.1
```
➡️ Target IP-তে কি security vulnerability আছে তা চেক করবে (Advanced)
