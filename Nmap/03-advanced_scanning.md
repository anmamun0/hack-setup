# 03-advanced_scanning

এই ফোল্ডারটি Nmap এর অ্যাডভান্সড স্ক্যানিং কৌশল ও টেকনিক নিয়ে কাজ করে। এখানে সার্ভিস ভার্সন ডিটেকশন, অপারেটিং সিস্টেম ডিটেকশন, স্ক্রিপ্ট স্ক্যানিং এবং স্টেলথ স্ক্যানিং সম্পর্কিত বিষয়গুলো বিস্তারিত আলোচনা করা হয়েছে।

---

## ১. service_version_detection.md

**সার্ভিস ভার্সন ডিটেকশন** হলো কোনো ডিভাইসের খোলা পোর্টে চলছে এমন সার্ভিসগুলোর নাম এবং তাদের ভার্সন নম্বর জানা।  
এতে জানা যায় কোন সফটওয়্যার চলছে এবং সেটির ভার্সন কী, যা ভলনারেবিলিটি খুঁজে পাওয়ার জন্য গুরুত্বপূর্ণ।  
উদাহরণ:  
```bash
nmap -sV <target-ip>
```
## ২. os_detection.md
অপারেটিং সিস্টেম ডিটেকশন দ্বারা লক্ষ্য ডিভাইসটি কোন অপারেটিং সিস্টেম (যেমন Windows, Linux, Android) চালাচ্ছে তা অনুমান করা হয়।
Nmap এর -O অপশন দিয়ে OS fingerprinting করা হয়।
উদাহরণ:

bash 
nmap -O <target-ip>
## ৩. script_scanning.md
স্ক্রিপ্ট স্ক্যানিং হলো Nmap এর NSE (Nmap Scripting Engine) ব্যবহার করে স্বয়ংক্রিয়ভাবে বিভিন্ন পরীক্ষা করা।
যেমন: ভলনারেবিলিটি চেক করা, পাসওয়ার্ড শক্তি পরীক্ষা, ডেটা সংগ্রহ ইত্যাদি।
উদাহরণ:

bash
Copy
Edit
nmap --script=<script-name> <target-ip>
অথবা সব স্ক্রিপ্ট চালাতে:

bash
Copy
Edit
nmap -sC <target-ip>
## ৪. stealth_scanning.md
স্টেলথ স্ক্যানিং এমন ধরনের স্ক্যানিং যা টার্গেট ডিভাইসের লগে ধরা কম দেয়।
এতে কমন TCP স্ক্যানের পরিবর্তে বিশেষ প্যাকেট ব্যবহার করে স্ক্যান করা হয়, যেমন SYN স্ক্যান (-sS), FIN স্ক্যান ইত্যাদি।
উদাহরণ:

bash 
```
nmap -sS <target-ip>
```
